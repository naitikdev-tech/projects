# Personal Portfolio Website

A modern, dark, responsive personal portfolio for Naitik, built with HTML, CSS, and JavaScript.

This is Version 1 of a portfolio that will grow throughout an engineering journey. The current goal is to master frontend fundamentals before moving to React and full-stack development.

- HTML

## Features

- Single-page responsive layout
- Modern dark, tech-focused design
- Semantic HTML structure
- Mobile navigation menu
- Smooth scrolling
- Scroll reveal animations
- Placeholder project cards for future work
- Easy-to-update contact and resume links
